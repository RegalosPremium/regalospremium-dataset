## Regla de uso

Antes de iniciar un bloque nuevo de diseño, desarrollo, integración o automatización:

1. revisar este índice;
2. consultar la LA aplicable;
3. buscar componentes previamente probados;
4. reutilizar o adaptar antes de reimplementar;
5. validar contra el objetivo comercial y el rol asignado;
6. registrar una nueva LA cuando el resultado aporte una decisión reutilizable.

## LA-0003 — regla operativa transversal

La solución debe demostrar criterio, iniciativa y consistencia con el objetivo.

- entender el propósito, no sólo la instrucción literal;

- aprovechar MariaDB, RDC, APIs, conectores y repositorios cuando correspondan;
